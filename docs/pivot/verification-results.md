# Verification results

[`verification-result.schema.json`](../../schemas/verification-result.schema.json) defines version 1 of a single validation outcome. It records the source (`local` or `hosted`), exact check, passed or failed status, exit code, evidence artifact, and optional environment identity. Exit code zero means passed; any positive exit code means failed. The additive `environmentIdentity` field is the local machine name for new local results and `github:owner/repository@commitSha` for mapped GitHub checks. Older version 1 results remain valid.

Local commands run through `AgentTool.RunArtifact` include a `verification` object in their existing process report. The report's existing exit code, summary, and artifact remain available. `VerificationResults.FromGitHubCheck` maps completed GitHub checks with success to passed and failure, timeout, cancellation, or action required to failed; pending and indeterminate conclusions cannot produce a result. The check's HTTPS details URL is its evidence artifact.
