# Typed judgments

The HTTP client posts state, model and a questions map to the configured System One endpoint.
Noul answers a yes/no proposition with a probability; Choice selects a key from named criteria;
Score evaluates an ordered 2–10 level rubric. Choice/Score require a valid probability distribution
and sufficient confidence. They are not a general coding or text generation interface.

Input examples and endpoint controls: [JEV documentation](../../../../../docs/jev.md).
API source: https://docs.typesafe.ai/introduction/quickstart
