# Conservative routing

Noul relevance >= 0.70: INCLUDE; <= 0.10: EXCLUDE; otherwise REVIEW.
Choice/Score confidence below 0.80: REVIEW. Probability is not a separate confidence field.
Read toolkit config/jev.json for customized thresholds. Never discard REVIEW. Failures keep
normal GPT behavior. Capability confidence may be stricter than the global default, and an
expected call count is not a quota to consume. Never exceed a maximum or weaken a zero budget.
These defaults are heuristic, not guaranteed calibration; evaluate
recall on representative fixtures before tightening exclusion. Security, authorization,
compatibility and calculations remain deterministic or human/Codex decisions.
